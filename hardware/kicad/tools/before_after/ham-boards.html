How this was measured

The EasyEDA files in hardware/easyeda-archive/ were converted with kicad-cli pcb import and checked with the current boards' rules (0.2 mm clearance and track, 0.3 mm drill, IPC-2221 power widths), with zones refilled. KiCad cannot import EasyEDA schematics from the command line, so "before" has no ERC count; the design-review errors were found in those same EasyEDA files. The VL V1.5 import shows no centre cutout, and the LM V2.8 outline is invalid as saved in EasyEDA.

Still open

  • MC C3: the RS-232 connectors are only safe with the external TTL-to-RS-232 modules fitted. True RS-232 levels would damage the Mega.
  • HC-05 Programmer: 5 V into the HC-05 RX pin. Low priority, since this board will be retired.
  • Main SW1: the Carling LT series is rated 0–85 °C; the 2025-06-05 flight saw −7 °C inside. The switch is set on the ground, not operated in flight.
  • MC C2 is left as is on purpose: the buck input arrives on wires from a barrel jack and switch.
